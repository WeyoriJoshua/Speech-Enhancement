# Data availability

VoiceBank+DEMAND, LibriSpeech, and the Microsoft DNS Challenge resources used in this study are publicly available from their respective original maintainers. Raw third-party audio is not redistributed in this repository.

The submitted PLOS ONE supporting-information package contains the complete case-level derived data underlying the external evaluation comprising **18,340 LibriSpeech+DNS cases**.

An archival reproducibility package has also been prepared containing:

- the exact publication notebooks for A0-A5;
- frozen-mixture/OOD evaluation utilities;
- derived in-domain and OOD results;
- selected best checkpoints for A0-A5; and
- integrity hashes.

The permanent archival URL/DOI must be inserted only after this exact versioned archive has been deposited and published. Until then, no DOI should be fabricated or pre-filled.
